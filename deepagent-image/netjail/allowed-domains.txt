# NetJail egress allowlist  (run-docker  NET_JAIL=1 / -NetJail).
#
# Each non-comment line = one domain the agent may reach over HTTP/HTTPS via the
# egress proxy. Subdomains are included automatically (listing example.com also
# allows api.example.com). Everything NOT listed is DENIED by the proxy.
#
# Plain domains only - one per line. No scheme, no path, no port:
#     example.com
#
# The agent never routes to the internet directly; it hands the hostname to the
# proxy, which enforces this list. To add access: add a line. To revoke: delete.
